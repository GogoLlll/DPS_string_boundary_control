# Струна с граничным управлением

Программа решает начально-краевую задачу для волнового уравнения на отрезке:

```
y_tt = a² y_xx,   0 < x < l;    y(0,x) = y0(x),  y_t(0,x) = y1(x);    y(t,0) = u(t),  y(t,l) = 0
```

По заданным l, a, начальным данным y0, y1 и управлению u(t) она находит движение струны y(t, x),
проверяет его и показывает результаты в графическом интерфейсе. Решение строится методом бегущих волн
(профили A, B) - точно в каждой точке, без сеток.

Программа состоит из двух частей:

- **общая часть** - прямая задача: движение струны при заданном управлении;
- **задача успокоения** (`wavesys/damping/`) - программа сама строит управление, после которого струна
  покоится к моменту T. Она подключена к общей части как отдельный модуль.

## Запуск

```bash
./run_gui.sh
```

Откроется страница в браузере (по умолчанию http://localhost:8765/).
Параметры: `--port N` - другой порт, `--no-browser` - не открывать браузер.

Первая установка (если нет папки `.venv`):

```bash
uv venv .venv && uv pip install --python .venv/bin/python -r requirements.txt
```

## Тесты


## Задача успокоения

В поле «Источник» кроме «Формула u(t)» есть три режима. Время T в форме - момент, к которому струна
должна успокоиться, поле «наблюдать после T» продлевает расчёт, чтобы было видно, что покой сохраняется

| Режим | Что строит |
|---|---|
| Успокоение: наименьшая стоимость | управление с наименьшим ∫u² dt. При T = 2·t₀ это оптимум лекции 6; при T > 2·t₀ - тот же профиль, разделённый поровну между повторами; при T < 2·t₀ - управление с наименьшим остатком |
| Успокоение: непрерывное управление | управление без скачков при T ≥ 2·t₀; ширина переходного слоя задаёт компромисс между стоимостью и плавностью |
| Успокоение за 2·t₀, затем покой | управление лекции 6 на (0, 2·t₀), затем левый конец неподвижен |

По времени различаются три случая (t₀ = l/a):

- **T ≥ 2·t₀** - успокоить можно всегда; при T > 2·t₀ управлений бесконечно много, выбирается самое дешёвое;
- **T < 2·t₀** - успокоить можно только особые начальные данные (возмущение у левого конца, бегущее
  влево). Для остальных программа сообщает, что покой недостижим, и строит управление с наименьшим остатком.

Вкладка «Успокоение» показывает: достигнута ли цель, стоимость и наименьшую возможную стоимость,
параметр r, минимальное время для данных и остаток, вычисленный двумя независимыми способами.
Параметр r можно задать вручную (например, r = y₀(0) даёт управление, согласованное с начальным отклонением).

Шесть примеров «Успокоение: …» в списке «Пример» покрывают все случаи

## Формулы

В полях y0(x), y1(x), u(t) записываются обычные выражения: `0.5*sin(pi*x/l)`, `0.4*t*ind(t, 0, t0)`.
Доступны параметры `l, a, t0, T`, постоянные `pi, e`, функции `sin, cos, tan, exp, log, sqrt, abs, sinh,
cosh, tanh, sign, min, max, where` и три вспомогательные: `pos(v)` = max(v, 0); `ind(v, lo, hi)` = 1 при
lo ≤ v < hi; `step(v)` = 1 при v ≥ 0. Степень - `^` или `**`.

Использование без интерфейса:

```python
from wavesys.problem import Problem
problem = Problem.from_text(l=1.5, a=2.0, T=3.0, y0="0.7*sin(pi*x/l)", y1="0", u="0.1*t")
solution = problem.solve()
print(solution.y(1.2, 0.5))        # значение в точке
print(solution.state_norm(3.0))    # насколько состояние далеко от покоя
```

Успокоение без интерфейса:

```python
from wavesys.damping import BaseProfile, EqualShareControl
from wavesys.problem import Problem
base = Problem.from_text(l=1.0, a=1.0, T=4.0, y0="0.8*(1 - x/l)", y1="0", u="0")
profile = BaseProfile(base.params, base.data, 4.0)                 # успокоить к T = 4
control = EqualShareControl(base.params, base.data, 4.0, profile.r_optimal())
solution = Problem(base.params, base.data, control, 5.0).solve()
print(profile.cost_min(), solution.state_norm(4.0))               # стоимость и норма в момент T (ноль - покой)
```

## Как добавить задачу управления

Образец - модуль `wavesys/damping/`.

1. Создать модуль с классом-наследником `wavesys.design.ControlDesigner` и реализовать `build(params,
   data, horizon, **options)`: он возвращает управление - наследника `BoundaryControl`.
2. Зарегистрировать его: `design.register(MyDesigner())` - и импортировать модуль в `wavesys/gui/api.py`.

Построитель появится в списке «Источник» в интерфейсе; решение, проверки и все вкладки будут работать с
его управлением без изменений.

Управление должно реализовать `slot(j, s, t0)` - значения на участке номер j в точках со смещением s
(моменты j·t0 + s). Обращение через пару «участок, смещение», а не через одно число t, нужно для
разрывных управлений: иначе из-за округлений на границе участка слагаемые рекурсии берутся с разных
сторон скачка.

## Как добавить вкладку

Написать модуль в `wavesys/gui/static/js/views/` с объектом `{ id, title, mount(root), update(data) }`
и вписать его в список `VIEWS` в `js/main.js`.
